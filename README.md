README – ZenithTuition


OVERVIEW

ZenithTuition is a Progressive Web Application (PWA) designed to connect a tutor with students. The project was developed using Node.js, Express.js, EJS, Bootstrap 5, and service workers for offline support.


LIBRARIES

The project uses the following additional libraries and frameworks:

express → Web server framework
ejs → Templating engine
express-session → Session authentication
bcrypt → Hashing
bootstrap → Responsive UI styling
dotenv → Environment variable management
